# GameNet v1 examples

`moving-circles-v1.cddl` extends the three GameNet type sockets with a minimal conformance-game schema. `driving-v1.cddl` specifies the simplified authoritative driving pilot payloads, while `driving-production-v1.cddl` specifies snapshots from the extracted production vehicle mechanics. `driving-configurable-v1.cddl` adds paused configuration epochs and client readiness for public host-controlled map transitions. The `.diag` files are CBOR diagnostic notation instances of the resulting `gamenet-message` root rule.

To validate with the Ruby [`cddl`](https://rubygems.org/gems/cddl) reference tooling:

```sh
cat ../gamenet-v1.cddl moving-circles-v1.cddl > /tmp/moving-circles.cddl

diag2cbor.rb < hello.diag > /tmp/hello.cbor
cddl /tmp/moving-circles.cddl validate /tmp/hello.cbor
```

Apply the same conversion and validation to the GameNet diagnostic files.

Direct Invite fixtures use their own root schema:

```sh
diag2cbor.rb < direct-invite.diag > /tmp/direct-invite.cbor
cddl ../direct-invite-v1.cddl validate /tmp/direct-invite.cbor

diag2cbor.rb < direct-response.diag > /tmp/direct-response.cbor
cddl ../direct-invite-v1.cddl validate /tmp/direct-response.cbor
```

These examples are documentation fixtures. TypeScript codec tests include the independently generated bytes and compare decoded semantics without depending on Ruby at runtime.
