- Complete mix true peak: at or below −1 dBFS.

## Interpretation

This report catches clipping, gross level regressions, unexpectedly flat dynamics, and large changes in the tire-critical 1–3 kHz or engine/bass region below 250 Hz. All scenarios use the production engine/tire worklets through the shared complete-game mixer. Band levels are diagnostics rather than pass/fail psychoacoustic masking scores, so listening review remains required.
